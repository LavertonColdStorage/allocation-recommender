Getting the export from dotWMS

Run Stock On Hand – ULD in dotWMS (opens in a new tab — log in first if needed), filtered to the warehouse/tenant you need. dotWMS exports this as .xlsx, not CSV — open it and use File → Save As → CSV UTF-8 (Comma delimited) (*.csv) before loading it below. A plain "CSV" save can mangle special characters; UTF-8 is the one that doesn't.
