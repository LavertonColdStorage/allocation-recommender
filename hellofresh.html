Load live stock from .wms

Reads current stock straight from .wms for the item codes you list - allocations, holds, locations and carton dates included, no exports needed. Then fills in the tenant, warehouse and one order line per code. Takes about 20–60 seconds depending on how many codes. Leave the item codes blank to load all of the tenant's stock - slower (a minute or two), so to speed it up, enter just the codes you want. The file upload below still works if this is unavailable.

Connection (set once on this PC)

Or: getting the export from dotWMS

Run Stock On Hand – ULD in dotWMS (opens in a new tab - log in first if needed), filtered to the warehouse/tenant you need. dotWMS exports this as .xlsx, not CSV - open it and use File → Save As → CSV UTF-8 (Comma delimited) (*.csv) before loading it below. A plain "CSV" save can mangle special characters; UTF-8 is the one that doesn't.

HelloFresh rules: pallets of exactly 40 cartons, one item and one production day each, oldest day first.
      Stored pallets may be broken down, and pallets in locations shared with other items are used (HelloFresh stock is double-deep only).
      At most one pallet per item may mix two days, and only to complete the order. Older days that can't make a full 40 are flagged, not used.

HelloFresh order lines for .wms

    
Key these into Shipping → Create Manual Shipment Order, one line each, using only
      Item Code, Preferred Pick ULD, Best Before Date and Quantity. Leave EST and the min/max date
      filters blank, and if you use Allocation, put the same value on every line - .wms falls back to the first
      line's value when they differ.
